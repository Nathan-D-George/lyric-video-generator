# Lyric Video Generator

This app allows you to generate your own lyric videos.

Link to app: [https://nathan-d-george.github.io/lyric-video-generator/](https://nathan-d-george.github.io/lyric-video-generator/)

## How it works
You can provide your audio file. Afterwards, create slide with lyrics that will change as the song progresses.
You are able to run through the song in Live Synchronization mode allowing for accurate time stamps to be placed per slide.
When you're happy you can export your lyric video to your local machine.

## Inputs
  - your audio mp3 file
  - a background image (optional)
  - lyrics

## Settings
  - Font size
  - Font colour
  - Text placement (x & y position, per slide)
  - Line Height
